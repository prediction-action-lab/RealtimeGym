Experiment and interpretation

Reactive uses thinking-disabled inference to select one action. Planning waits for a complete thinking-enabled plan while the environment advances. Agile uses the available partial planner output to guide a reactive action.

One Qwen3-8B checkpoint is loaded per H200 job. Planner and reactor generation run sequentially; exact output-token prefixes simulate their parallel timing. These results measure token-budget behavior, rather than real-time serving performance.

The pilot uses medium Freeway, 8,192 tokens per step and a 4,096-token reactive budget. The trend experiment varies difficulty (easy, medium, hard) and time pressure (32K, 16K, 8K, 4K tokens per step), with separate reactive budgets for the two sweeps.

Only completed games receive final scores. Comparisons use matched environment and sampling seeds. Two independent environment seeds make this an exploratory study. Audits replay actions, verify final scores, and decode saved planner tokens to check causal visibility. Overlong valid reactive answers use the first action, with explicit diagnostics.
